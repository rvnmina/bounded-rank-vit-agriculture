# Paper notes

One markdown file per reference paper. Each file has the same layout:

1. **Bibliographic entry** (exact author list, venue, year, DOI).
2. **Abstract** — quoted verbatim from the PDF.
3. **Key contributions** — bulleted.
4. **Method** — a paragraph or diagram-friendly description.
5. **Results** — the reported numbers that matter.
6. **My take** — one paragraph on what I learned and how it feeds MTP-2. *This is Ravindra's reading — the paper authors bear no responsibility for it.*
7. **Open questions** — things the paper does not answer that could seed follow-up work.
